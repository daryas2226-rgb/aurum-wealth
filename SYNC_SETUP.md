# Синхронизация телефон ⇄ ноутбук

Данные больше не живут только в браузере устройства. Теперь они хранятся в облаке
(Supabase, проект `personal-os`) и привязаны к твоему Telegram ID. Оба устройства
видят одно и то же.

## Что изменилось в коде
- `app/api/state/route.ts` — новый серверный роут. Проверяет подпись Telegram
  (по `TELEGRAM_BOT_TOKEN`) и читает/пишет состояние в Supabase. Чужие не имеют доступа.
- `public/wealth.html` — при старте сначала смотрит в облако, потом рисует экран;
  любое изменение автоматически уходит в облако; при возврате в приложение данные
  подтягиваются с другого устройства.
- Таблица `public.wealth_state` в Supabase (RLS закрыт — доступ только через сервер).

## Запуск (3 шага)

### 1. Добавить один секрет в Vercel
Vercel → проект `aurum-wealth` → Settings → Environment Variables → добавить:

- **Name:** `SUPABASE_SERVICE_ROLE_KEY`
- **Value:** ключ `service_role` из Supabase
  (Supabase Dashboard → Project Settings → **API Keys** → строка **service_role**, нажми «Reveal» и скопируй)
- Environment: Production (и Preview, если нужно)

`SUPABASE_URL` уже зашит в код, добавлять не обязательно.

### 2. Задеплоить
`git add -A && git commit -m "cloud sync" && git push` — Vercel соберёт автоматически.

### 3. ВАЖНО: первой открыть приложение НА ТЕЛЕФОНЕ
На телефоне лежат твои настоящие данные. При первом открытии после деплоя они
сами уедут в облако. Только после этого открывай на ноутбуке — он подтянет ровно
те же данные. (Если случайно откроешь ноут первым — ничего страшного: стартовые
данные ноутбука в облако не выгружаются, телефон всё равно станет источником.)

Готово. Дальше всё синхронизируется само.
